A · lassen + Infinitiv

核心：主语安排或允许另一人做事。lassen 按人称变位，另一动作的原形放句末。可以把它理解为“让人做／请人代办”。
人称lassen人称lassen
ichlassewirlassen
dulässtihrlasst
er / sie / eslässtsie / Sielassen
Sie repariert ihr Handy.
她自己修手机。
Sie lässt ihr Handy reparieren.
她让别人修手机。
Sie hat ihr Handy reparieren lassen.
她已经让人修了手机。
Wir ließen den Drucker überprüfen.
我们当时安排检查打印机（Präteritum）。
完成时不要写错： hat reparieren lassen，不能写 hat repariert gelassen。这里出现的是两个原形（Ersatzinfinitiv）。

B · Folgen ausdrücken：结果从句

表达方式句子形式常见职场句子
sodass / so dass结果从句，变位动词在句末Der Server fiel aus, sodass wir nicht arbeiten konnten.
so … dassso + 形容词/副词，后面 dass 从句Die Schulung war so hilfreich, dass alle viel gelernt haben.
deswegen / darum / daher结果主句，变位动词在第二位Die Frist ist knapp. Darum arbeiten wir länger.
原因 Frage：Warum?

Weil der Server ausgefallen ist, müssen wir warten.

因为服务器坏了，所以我们得等。
结果 Frage：Mit welcher Folge?

Der Server ist ausgefallen, sodass wir warten müssen.

服务器坏了，导致我们必须等待。
目的 Zweck：damit

Wir buchen eine Schulung, damit alle sicher arbeiten können.

我们预订培训，目的是让大家安全操作。
结果 Folge：sodass

Wir haben eine Schulung gemacht, sodass alle jetzt sicher arbeiten können.

培训已经举办，结果是大家现在可以安全操作。
三秒记忆法：damit → 想达到的目标；sodass → 已产生或推导出的结果；deshalb / deswegen / darum / daher → 结果主句，动词仍在第二位。
