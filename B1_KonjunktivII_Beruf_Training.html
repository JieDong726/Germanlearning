第二虚拟式：过去的遗憾与非现实假设

Konjunktiv II · Irreale Bedingungen, Wünsche, Vergangenheit und Modalverben

A · 语法一眼速记（先记这四个句型）

先理解时间，再选形式

参考德语语法教材的“形式—用法—例句”结构重新整理。图片中的 Was passt zusammen? 是本页主要练习方式。

① 现在／将来的非现实假设

Wenn … hätte / wäre, würde / könnte … + Infinitiv.
现实中条件不成立；例如现在预算不够。

② 过去没有发生的假设

Wenn … gemacht hätte / gekommen wäre, hätte / wäre … + Partizip II.
表达“当时如果……，本来就会……”。

③ 过去本可以／本应该

hätte(n) + … + machen können / sollen / müssen
双不定式（Ersatzinfinitiv）：hätten prüfen sollen，不是“hätten geprüft sollen”。

④ 过去的条件影响现在

Wenn … gemacht hätte, würde / könnte ich jetzt …
先发生的是过去，结果发生在现在；注意 damals / heute / jetzt。

B · 图片对应的四个示范句

德语 + 中文
Sie wünschte, dass es den Rock auch in Größe 42 geben würde.她希望这条裙子也有 42 码。（愿望）
Wenn er den Vorschlag gestern gemacht hätte, hätten wir ein besseres Angebot finden können.如果昨天提出建议，我们本来能找到更好的报价。（过去假设 + 能力）
Wenn ich keine Bedenken gehabt hätte, würde ich jetzt in Paris arbeiten.如果当时没有顾虑，我现在就在巴黎工作。（过去 → 现在）
Wir hätten vorher über alle Möglichkeiten nachdenken sollen.我们本来应该提前考虑所有可能性。（过去本应做）
小心区分：Ich konnte = 当时确实能够；Ich hätte … machen können = 当时本来能够（但不一定做了）。「过去本应」用 hätte … machen sollen。另外，würde gemacht haben 不是这里最自然的标准表达；过去假设通常用 hätte gemacht。

C · 完成时辅助动词与双不定式

B1 核心变化
现在假设过去反事实

主语haben → Konjunktiv II
ich / duhätte / hättest

ihr / sie,Siehättet / hätten
展开：第一虚拟式与过去式会混淆吗？

这里全部练的是第二虚拟式。hatte 是实际过去，hätte 是假设；war 是实际过去，wäre 是假设。过去未实现的条件常用 Wenn ich … gemacht hätte。
